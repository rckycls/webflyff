# D - Online research: FlyFF PC bank and mail (V15-era)

Note: The search tool gave only summaries. Fandom pages returned HTTP 402 (blocked). web.archive.org is blocked. No YouTube hits. So bank detail is thin.

## Bank
Source A: https://flyff-wiki.gpotato.com.br/wiki/New_Pang_Tutorial (Gpotato wiki, marked certified for V12 - old PC client)
- Bank is opened by the "(Public Office)" NPC in each town. Menu entry: "Deposit".
- In Flaris, the NPC is Julia, next to the mail box.
- Password is 4 digits. First time: enter it twice to register, then once more to open the bank. "Only way to get to your stuff."
- Page has screenshots named "Password Settings", "Open Bank", "Bank" (not described in text; I could not see them).
- Penya in/out, slots, fees: NOT covered.
Source B: https://flyff-wiki.gpotato.com.br/wiki/New_Player_Guide
- Calls it "bank pin"; says to enter the pin from the Character Creation window (so the pin is set at character creation in this era's client).
- Number buttons on the pin window are in random order.
- Deleting a character clears its bank (restoring a character does not restore the bank).
Source C (guild text from search summary): https://www.en-galalab.flyff.com/guilds
- Guild Warehouse is at the Bank NPCs; penya removal works like the bank.
Source D: https://flyff-wiki.gpotato.com.br/wiki/Trading
- Max penya held: 2.1 billion (2,147,483,647) - cited for PC by https://madrigalinside.com (search summary).
- Wiki /wiki/Bank gave 404. Not found: slot counts, 3-character layout, fees, forbidden items, "Custody" name. (My own memory, unverified: the V15 bank had 3 character tabs; do not rely on it.)

## Mail
Source E: https://flyff-wiki.gpotato.com.br/wiki/Mail_System (old PC client wiki)
- Mailbox: red "Post Box" next to the Public Office NPC in Flaris, Saint Morning, Darkon.
- Send fee: 500 penya per mail, plus any penya attached.
- Post Box capacity: 50 mails. Over 50, you cannot receive new mail until below 50.
- Send window: Receiver (type name, case exact, or pick a friend from drop-down); Title (max 32 bytes; attaching an item sets title to item name, editable); Message (max 256 chars, Enter = new line); Item box (ONE item per mail, full stack OK, right-click to remove; Premium Shop items cannot be sent); Penya field (deducted on send); Send button (no undo; no sent-mail list).
- Receiving: pop-up lower right, and the messenger shows a flashing mail icon.
- Received Mail tab at any Post Box. Each row: attachment icon (left), sender + title, days remaining (right).
- Double-click opens a mail. Drag item/penya to inventory to take it; if not taken, lost with the mail. Reply button. Delete button.
- Mail kept 15 days. Sender "unknown" = sender character deleted.
- Late fees: table says 1-9 days 0 penya, day 10 = 1 penya, days 11-15 "not yet listed" (wiki incomplete). Unclear what happens exactly at expiry beyond "lost".
Source F (private server, NOT original): https://newmadrigal1.gitbook.io/new-madrigal-wiki/game-features/system/mail-system
- Up to 7 items per mail; items go to a Vault; envelope notification icon. Differs from the 1-item rule above.

## Agree
- Public Office NPC + Julia (Flaris) next to the mailbox (A, E, F).
- 4-digit bank password (A, B).
- Premium items cannot be mailed.
## Disagree / unclear
- Items per mail: 1 (E, original) vs 7 (F, private server).
- Bank pin set at character creation (B) vs first-use at NPC (A).
- Late fee wording vs "kept 15 days" - expiry result not documented.
## Gaps
- Bank layout, slots, penya limits in bank, fees, forbidden items, 3-character view.

### R1: The raised pet in the world (apps/client)

- Own state: `OwnState` keeps the summoned slot (`petSlot` from the own ADD_OBJ; PET_CALL and PET_RELEASE about the own
  mover set and clear it, `DPClient.cpp:16398-16448`); PET replaces the item's pet and, with a flag, its `itemId`
  (`CPet::GetItemId`, `pet.h:147-152`) (:16540-16567); PET_STATE, PET_SET_EXP, PET_FEED update it; events for the
  window and the sounds.
- Other movers: `petId` (`MAKELONG( index, level )`) and name from `AddedPlayer.pet`, PET_CALL, PET_LEVELUP,
  PET_RELEASE, SET_PET_NAME.
- `CMover::ProcessPet` (`Mover.cpp:10839-10929`): a client-made mover (no server id) for each mover with a pet: model
  `CPet::GetIndex` (`pet.cpp:390-401`; `pets.json`), name, stand motion, the owner's position; rebuilt on a level-up
  (`PetLevelup`, `:10959-10967`); deleted on release (`PetRelease`, `:11180-11190`, `ItemGnCollector.wav`); the
  level-up sound `PCSkillCastCheer.wav` (`CreatePetSfx`, `:11148-11178`). Texture set by `textureEx` (C1).
- `CAIEgg::MoveProcessIdle` (`pet.cpp:493-570`): the point 1 m left or right of the owner, the nearer one, `SetDestPos`
  when farther than 1 m; the pet's speed from `propMover` (the egg's `AII_EGG` speed rule, `moverRules.ts:15`).
- Picking: another player's raised pet is never picked (`World3D.cpp:2703-2707`); the own one is, and its menu is
  `MaFl_Pet`'s (`MMI_PET_STATUS`, `MMI_PET_RELEASE`; R2 wires the actions).
- The S sparkle: `CreatePetParticle` (`Mover.cpp:10802-10833`, `g_ParticleMng` kinds 13-23); port the needed part of
  `CParticleMng` and list any picture C1 must still convert.
- Tests in the pretend world (testkit writers from M0).
